# For testers

Send this page to your testers.

## Installing a test build

1. Open the link the publisher sent you.
2. Choose **Sign in with Google** and pick the account the publisher invited. Use the same Google account your Chrome profile is signed in to.
3. If the build is ready, choose **Open in Chrome Web Store**, then **Add to Chrome**. Chrome lists the permissions the extension asks for.

Updates install automatically. When the test ends, remove the extension from `chrome://extensions`.

## What the link might say

| Message                                              | What to do                                                                |
| ---------------------------------------------------- | ------------------------------------------------------------------------- |
| Not installable yet                                  | The Web Store is still reviewing this version. Try again later.           |
| This account isn't on the tester list                | Choose **Use another account**, or ask the publisher to add your address. |
| This link was replaced                               | Ask the publisher for the new link.                                       |
| This link has expired, or the test window has closed | Ask the publisher whether there is a newer build.                         |
| This test has ended                                  | The publisher withdrew the build. You can remove it.                      |

## The Web Store says the item is unavailable

For private test builds, the Web Store checks the Google account your **Chrome profile** is signed in to, not the one you used on the link page. Switch Chrome to the invited account, or ask the publisher to add the account you use in Chrome.
